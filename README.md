# Camlab

使用 SwiftUI、AVFoundation、Core Image 與 Metal 的 iPhone 相機。預設在 App 內套用配方、即時預覽與編輯照片。調色使用 Camlab 的區域亮度與色彩處理；設定中另保留 iPhone「照片」手動調整、讀回相簿結果的備用流程。

## 執行

以 Xcode 開啟 `Camlab.xcodeproj`，在實體 iPhone 執行。最低系統版本設為 iOS 26.0。專案仍可在 iPad 編譯，主要拍攝介面以 iPhone 為驗證重點。模擬器沒有實際相機，可檢查參數、配方、相簿流程與橫直向布局。

## 原生照片流程（設定中的備用選項）

1. 先選擇或編輯配方，再到設定開啟「使用原生照片調整流程」後拍攝。取景器為原色預覽，配方數值不會套入原圖。重新選取內建拍攝風格會返回 App 內即時調色。
2. 原圖儲存後留在相機繼續拍攝；長按圖庫選「開啟最近照片」可進入「原生照片流程」。手動切換到 iPhone「照片」，開啟同一張照片，依清單輸入數值並點完成。若需從原圖重做既有照片，先在「照片」回復原狀。
3. 返回 Camlab，會重新讀取同一 asset 的相簿目前版本；也可按「重新讀取」。若僅有選圖器存取而無 asset 權限，須按「選擇照片」重新選取同一張。
4. 「分享相簿版本」直接複製 Photos 回傳的影像資料，依實際格式使用 HEIC／JPEG／PNG 等副檔名，不重新套配方或編碼。分享目的地本身仍可能轉檔。預覽呈現也受裝置及系統 HDR 顯示影響，這不是像素一致的螢幕校驗。

這個流程不會自動開啟指定照片或代填原生數值；相簿目前版本可能來自任一編輯器，Camlab 不宣稱辨識了編輯來源。原生引擎由使用者在「照片」內操作，Camlab 負責保存原圖和接回結果。設定「使用原生照片調整流程」預設關閉；本次更新會將先前的原生預設遷移回 App 內調色一次，之後尊重使用者保存的選擇。舊待儲存照片依原本模式處理，不會因設定切換丟失已做的編輯。

## 拍攝與配方

- 開啟 App、返回前景或離開照片編輯時自動啟動相機；等待首張預覽時取景器顯示純黑，第一張畫面就緒後直接顯示。暫時性啟動失敗會自動重試一次，已啟動的擷取意外停止時會嘗試自動恢復；仍失敗才提供「重試開啟相機」。未授權時引導開啟權限，無相機的模擬器只顯示限制說明。
- 內建 12 種拍攝風格：復古、暖調底片、日系清透、電影、經典黑白、柔光人像、夕陽、冷調、鮮明、霧感、城市街拍、咖啡暖棕，另保留「原色」。橫直向皆可點上方風格名稱開啟完整清單；主畫面不常駐風格快捷列。
- 風格已完成六張公開攝影樣本的四輪對照；新增柔和膚色範圍保護、單調亮部壓縮，以及提亮前的暗部分區降噪，涵蓋人像、日景、室內、夜景與夕陽。可開啟 [原圖／舊版／新版比較頁](Design/StyleCalibration/comparison.html)，方法、數值變動及樣本限制見 [校色紀錄](Design/StyleCalibration/README.md)。這不是 iPhone 實拍或色卡校正；保存的自訂配方數值與既有照片檔案不改寫；重新渲染配方時會使用新的成像流程。
- 選取內建風格會啟用 App 內即時預覽，拍照直接套用同一組調色數值存入相簿；若先前開啟原生照片流程，選取風格會將其關閉。重開 App 恢復上次選擇。內建風格可微調後另存自訂配方，但不可覆寫、改名或刪除；原有自訂配方保留。
- 點取景器左側的風格按鈕，展開後上下滑動滾輪即可切換原色、內建風格或自訂配方。再點一次側邊按鈕或輕點空白處即可收合。調整後按「另存新配方」命名保存，或按「更新配方」覆寫目前配方。在相機設定的「管理配方」可重新命名或刪除自訂配方。
- 每次啟動恢復上次選用配方的已保存數值。未儲存微調不寫入配方；切換配方也直接捨棄微調。
- 點上方滑桿圖示展開可收合控制區。「調色」（原生流程為「配方清單」）包含曝光、增艷、亮部、陰影、對比、亮度、黑點、飽和度、自然飽和度、色溫、色調、銳利度、清晰度、降低雜點、暈邊，共 15 項手動調整。銳利度、清晰度與降低雜點採 0 至 100；其餘採 −100 至 100，均為整數，滑桿與鍵盤依選項切換範圍。
- 銳利度強化細小邊緣，清晰度增加較大範圍的局部對比；兩者依膚色、暗部與強邊界減弱處理，以限制顆粒及白邊。降低雜點在提亮前處理細碎雜訊；暈邊正值壓暗邊緣、負值提亮。在 Camlab 近似模式中，四項效果共用於即時預覽、拍照成品、匯入編輯與分享，能保存到配方及相簿調整資料；舊配方缺少的新欄位預設為 0。
- 點數值使用畫面內鍵盤；在近似模式中拖動滑桿或輸入有效數值會立即影響預覽；原生模式只更新手動清單。直向控制在取景器下方，橫向控制在側邊窄列，調整與輸入期間保持預覽可見。
- 左上角可切換九宮格與水平線，工具列中央顯示目前的風格名稱，右側提供調整與設定。直向工具列在取景器上方，底部平時只顯示圖庫、快門與翻轉相機；展開調整時才出現圓角面板。原圖比較位於調色面板，收合後自動返回效果預覽。橫向面板維持滿高，參數列表可以捲動，下方固定數值與滑桿；數字鍵盤利用面板高度。
- 調整面板、配方選單與數字鍵盤加入短過場，選取狀態和構圖輔助線使用淡化；遵循系統「減少動態效果」，不對即時相機數值套用延遲動畫。
- 「拍攝」控制 ISO、快門、對焦、白平衡、拍攝亮度與變焦。這些硬體設定和配方調色各自控制；可恢復自動模式。快門接受分數或秒數，ISO／快門使用對數滑桿。
- 單指輕點取景器可對焦，雙指張開可放大、合攏可縮小。雙指變焦從目前倍率開始，並同步顯示在底部倍率列。前鏡頭與橫直向的點選座標會換算回感測器座標。手動曝光不會因點對焦而改回自動。
- 取景器底部列出目前鏡頭的預設倍率，可點選或拖動切換，也可在取景器用雙指縮放。後置多鏡頭只在倍率改變時允許系統重新選擇實體鏡頭，固定倍率拍攝時維持取景視角。有超廣角時提供 0.5×，望遠倍率依硬體回報顯示。切換前後相機時回到顯示倍率 1×。
- 主操作列依序為圖庫、快門、翻轉相機。點一下快門拍一張，原地按住快門即可連拍，取景畫面持續顯示，取景器顯示本輪已拍張數，放開即停止並保留最後張數。系統允許時，單拍與連拍都會關閉快門聲。相機就緒且儲存佇列有空位時才會拍下一張。右側翻轉按鈕可切換前後相機，取景畫面以短暫模糊和翻面過場銜接。調整參數移至上方滑桿圖示，相機設定位於上方齒輪。
- 九宮格與水平線可從取景器左上角或相機設定的「構圖輔助」分別開關；水平線使用 Core Motion，接近水平時顯示黃色。手機平放、缺少有效方向資料時不顯示，真機需驗證方向與反應。

Camlab 調色參數名稱對照 iPhone「照片」，實際使用自有 Core Image 處理，並非 Apple 私有演算法的複製。陰影與增艷的暗部依像素及鄰近亮度加權；負向亮部使用連續、單調的壓縮曲線，調色後的極亮通道再平滑收斂。色溫／色調及正向飽和度增量會依原圖暖色範圍部分衰減，以減少膚色染色；這不是人臉辨識，相近暖色物體也可能受影響。增艷不再額外增加飽和度。對比曲線保留黑白端點，色溫與飽和度在感知 RGB 中處理，色溫偏移在純黑處淡出。預覽、匯入編輯與完整尺寸成品使用同一處理函式。

目前以使用者提供的同一張夜景及八項配方完成第一輪校正，完整輸出為 5712 × 4284。轉為相同尺寸 sRGB 後，相對原生參考的平均 RGB 絕對誤差由上一版 8.91 降至 7.96（0–255 尺度）；這不是相似度百分比，也不代表其他照片或各滑桿已與原生一致。白天、人像、逆光及個別滑桿仍待原圖／原生結果對照；真機預覽效能亦待測量。既有配方數值保留，重新套用使用新版處理，已輸出照片不自動改寫。重現工具為 `Tools/Calibration/render_recipe_comparison.py` 與 `Tools/Calibration/measure_recipe_comparison.py`。

## 相簿與重新編輯（Camlab 近似模式）

照片使用獨立 `AVCapturePhotoOutput`，不使用預覽截圖。採鏡頭支援的最大、至多約 24 MP 尺寸，處理時正規化方向、保留尺寸及拍攝資訊。預覽與成品共用配方處理函式，系統拍照處理造成的差異仍需真機比較。

支援重疊拍攝的鏡頭會在上一筆請求送達拍照輸出後檢查系統就緒狀態，可用時立即送出下一張。其他鏡頭等相機交回 JPEG 後，即可與上一張原圖的寫入並行。最多兩張同時拍攝或暫存，總共預留 16 張拍攝及儲存位置，滿載時等到有空位再續拍。完整尺寸的渲染及儲存依拍攝順序逐張進行，每張使用按快門時的配方快照。維持原本品質優先策略、照片尺寸與 JPEG 0.96 編碼品質。處理中的照片不出現在待重試清單，失敗或 App 終止留下的原圖則可從待儲存照片恢復。

新拍照片透過一次 PhotoKit 交易將原圖、調色成品與配方調整資料寫入同一筆相簿照片。成功後相簿中是同一筆照片，可取回原圖重新調色。App 只持續保存配方、設定與照片識別碼；完成寫入後清除照片暫存。

儲存需要相簿讀寫權限，以便保存原圖並提交可重編輯的結果。拒絕或寫入失敗時，原圖、成品及重試資料保留於 Documents/Captures；主畫面顯示待儲存數量，可開啟並重試或分享。建立原圖前先寫入建立意圖，並在 PhotoKit 交易提交前以原子檔案記錄 placeholder 的 asset 識別碼；重試會重用該 asset。PhotoKit 確認最終儲存後再記錄完成狀態，最後才清除暫存。未完成的拍攝暫存不自動過期。

App 重開或返回前景時，已具相簿權限便自動掃描待儲存原圖，依拍攝順序分批補入最多 16 張的佇列；每張保留完整渲染設定，不使用重開後目前選取的配方。每次執行對同一張自動嘗試一次，失敗保留原圖與提示，避免無限重試；權限尚未開啟不自動彈出授權。正在編輯的待儲存照片不會同時交給自動恢復。

`LibrarySave.json` 與渲染紀錄分開保存，包含建立中／可重試／已建立／已完成狀態。同張照片的同時儲存請求共用一個工作；若 Photos 已建立原圖但 `Capture.json` 尚未更新，從獨立紀錄接回原 asset，必要時以含拍攝 UUID 的原始檔名核對。已完成但尚未清理的項目不重送成品。識別碼無法讀取、紀錄損毀、或建立中交易無法確認時，保留待儲存項目並提示，不以新建副本來猜測恢復；因此無法確認的少數情境不宣稱能自動完成。

快門左側的「圖庫」按鈕可匯入照片，有本次拍攝縮圖時顯示縮圖，否則顯示有邊框的照片圖示；橫向時位於快門上方。長按照片可預覽。按相簿右上角「多選」後，直接橫向拖曳即可選取連續範圍，也能跨列繼續選取；從已選照片開始拖曳則取消選取該範圍。拖到上下邊緣會自動捲動。勾選後按「刪除 N 張照片」，由 iOS 一次確認整批刪除，完成後留在相簿。長按圖庫按鈕可重新開啟最近一筆。選到可存取的 Camlab 照片時讀取其原圖與調整資料，儲存更新同一筆；其他來源照片另存新的成品。若受限相簿權限無法讀取 asset，系統選圖器交付的影像會作為新匯入來源處理。

拍後調整與匯入編輯不會每次拖動就儲存，按「儲存成品」才寫入相簿；可比較來源圖、成品或分享完整尺寸 JPEG。來源圖若已有其他 App 編輯，使用 PhotoKit 可提供的編輯基底，不宣稱能重建其他 App 的配方。

從相簿匯入後，編輯頁將照片限制在可用範圍內，頂部完成按鈕與控制區底部的儲存／分享固定顯示。直向調整區位於照片下方，橫向位於右側；參數與數字鍵盤在空間不足時可捲動，配方選單使用獨立面板。原圖比較採淡入淡出。

刪除 App 會移除尚未存入相簿的暫存。從相簿刪除照片後，Camlab 不另留永久照片備份。

## 驗證與限制

單元測試涵蓋配方保存／重啟／原色／微調捨棄／改名／刪除、整數驗證、11 項參數像素變化、零值原圖、拍攝暫存與 asset 記錄／清理、點選對焦座標、水平角度，以及原有相機參數、照片方向與預覽呈現測試。

UI 測試檢查直向與橫向輸入仍有足夠預覽、配方重啟後的數值、九宮格／水平線與倍率入口。相簿整合測試限定已授權的模擬器，驗證原圖、配方資料、重複編輯同一 asset 與暫存清理。

真機需確認相機啟動、各鏡頭支援範圍、10× 操作、點對焦、感測水平線、照片尺寸與方向、相簿完整／受限／拒絕權限、背景中斷與重試，以及預覽／成品和 iPhone「照片」的效果對照。最低版本已編譯檢查，尚需 iOS 26.0 實機驗證。

相機工作與硬體變更在獨立序列佇列執行，影格只保留最新一張；Metal 預覽最多一個待完成工作。擷取啟動後立即非同步準備 Deferred Start 拍照輸出，與 Metal 調色預覽並行；快門由系統拍照就緒回報啟用，不再等待首張調色預覽。返回相同鏡頭且格式不變時重用設定；重複啟動不清除現有影格。快門前會驗證參數，只有請求值與硬體回報不同時才重新套用；照片尺寸與品質策略不變。圖庫按鈕的縮圖在背景解碼成顯示尺寸，更新快門或連拍張數時可重用。Xcode Console 可篩選 `CameraStartup`，其 discovery／configuration／startRunning 為工作時間，first preview presented 等為累積時間，不可相加。`shutter ready` 從 App 要求開啟相機起算（包含權限與裝置搜尋）；`shutter request reached output` 衡量按快門到提交拍照的等待。真正冷啟動與返回前景的耗時仍需真機量測，模擬器不提供相機效能數據。

時序檢查：硬體滑桿保留 60 ms 合併更新，但最後一筆送出後立即解除調整鎖定，不再空等下一輪。切換鏡頭的舊結果不得覆蓋返回前景後的新啟動狀態。拍照逾時只結束呼叫端等待，delegate 仍保留到系統最終回呼；重複與逾時競態只能回傳一次結果。提交拍照前再次檢查目前格式支援的尺寸及 JPEG，無效時走停止後的自動恢復。切換前後相機仍需停止、設定及重啟擷取；自動拍攝保留品質優先，下一張快門只等待系統交回照片、原圖暫存及拍照輸出重新就緒；配方處理及相簿儲存使用有容量上限的獨立工作佇列。

背景與連拍：拍攝／原圖暫存及儲存佇列會預先申請有限的 UIKit 背景執行時間，完成或期限到達時結束申請。期限到達後不再啟動後續照片工作，已排入的原圖保留，返回前景後繼續；停止相機或開啟編輯器不會取消儲存佇列。相機退到背景仍會停止擷取，若 JPEG 已成功交回，即使最後收尾回呼報錯也保留照片；若尚未交回有效照片就被系統中止，會回報拍攝失敗，不能保證取得該張影像。原圖以原子寫入完成前先保存重試紀錄，重新啟動可發現已完成暫存的原圖；只有紀錄但尚無原圖的項目不列為可重試照片。拍攝尚未收尾（包含逾時後仍在收尾）時不更換鏡頭輸入。強制終止 App 或系統尚未交付照片的情境仍需真機測試，不宣稱背景可無限執行或零漏失。
