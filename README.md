# Camlab

使用 SwiftUI、AVFoundation、Core Image 與 Metal 的 iPhone 相機。預設在 App 內套用配方、即時預覽與編輯照片。調色使用 Camlab 的區域亮度與色彩處理；設定中另保留 iPhone「照片」手動調整、讀回相簿結果的備用流程。

## 執行

以 Xcode 開啟 `Camlab.xcodeproj`，在實體 iPhone 執行。最低系統版本設為 iOS 26.0。專案仍可在 iPad 編譯，主要拍攝介面以 iPhone 為驗證重點。模擬器沒有實際相機，可檢查參數、配方、相簿流程與橫直向布局。

## 原生照片流程（設定中的備用選項）

1. 先選擇或編輯配方，再到設定開啟「使用原生照片調整流程」後拍攝。取景器為原色預覽，配方數值不會套入原圖。重新選取內建拍攝風格會返回 App 內即時調色。
2. 原圖儲存後顯示「原生照片流程」。手動切換到 iPhone「照片」，開啟同一張照片，依清單輸入數值並點完成。若需從原圖重做既有照片，先在「照片」回復原狀。
3. 返回 Camlab，會重新讀取同一 asset 的相簿目前版本；也可按「重新讀取」。若僅有選圖器存取而無 asset 權限，須按「選擇照片」重新選取同一張。
4. 「分享相簿版本」直接複製 Photos 回傳的影像資料，依實際格式使用 HEIC／JPEG／PNG 等副檔名，不重新套配方或編碼。分享目的地本身仍可能轉檔。預覽呈現也受裝置及系統 HDR 顯示影響，這不是像素一致的螢幕校驗。

這個流程不會自動開啟指定照片或代填原生數值；相簿目前版本可能來自任一編輯器，Camlab 不宣稱辨識了編輯來源。原生引擎由使用者在「照片」內操作，Camlab 負責保存原圖和接回結果。設定「使用原生照片調整流程」預設關閉；本次更新會將先前的原生預設遷移回 App 內調色一次，之後尊重使用者保存的選擇。舊待儲存照片依原本模式處理，不會因設定切換丟失已做的編輯。

## 拍攝與配方

- 內建 12 種拍攝風格：復古、暖調底片、日系清透、電影、經典黑白、柔光人像、夕陽、冷調、鮮明、霧感、城市街拍、咖啡暖棕，另保留「原色」。直向快門上方左右滑動即可選用，橫直向皆可點上方風格名稱開啟完整清單。
- 風格已完成六張公開攝影樣本的四輪對照；新增柔和膚色範圍保護、單調亮部壓縮，以及提亮前的暗部分區降噪，涵蓋人像、日景、室內、夜景與夕陽。可開啟 [原圖／舊版／新版比較頁](Design/StyleCalibration/comparison.html)，方法、數值變動及樣本限制見 [校色紀錄](Design/StyleCalibration/README.md)。這不是 iPhone 實拍或色卡校正；保存的自訂配方數值與既有照片檔案不改寫；重新渲染配方時會使用新的成像流程。
- 選取內建風格會啟用 App 內即時預覽，拍照直接套用同一組調色數值存入相簿；若先前開啟原生照片流程，選取風格會將其關閉。重開 App 恢復上次選擇。內建風格可微調後另存自訂配方，但不可覆寫、改名或刪除；原有自訂配方保留。
- 點取景畫面上方的配方名稱切換；「原色」固定可選。調整後按「另存新配方」命名保存，或按「更新配方」覆寫目前配方。選單提供改名與刪除，沒有直接複製功能。
- 每次啟動恢復上次選用配方的已保存數值。未儲存微調不寫入配方；切換配方也直接捨棄微調。
- 點「調整」展開可收合控制區。「調色」（原生流程為「配方清單」）包含曝光、增艷、亮部、陰影、對比、亮度、黑點、飽和度、自然飽和度、色溫、色調、銳利度、清晰度、降低雜點、暈邊，共 15 項手動調整。銳利度、清晰度與降低雜點採 0 至 100；其餘採 −100 至 100，均為整數，滑桿與鍵盤依選項切換範圍。
- 銳利度強化細小邊緣，清晰度增加較大範圍的局部對比，降低雜點平滑細碎雜訊；暈邊正值壓暗邊緣、負值提亮。在 Camlab 近似模式中，四項效果共用於即時預覽、拍照成品、匯入編輯與分享，能保存到配方及相簿調整資料；舊配方缺少的新欄位預設為 0。
- 點數值使用畫面內鍵盤；在近似模式中拖動滑桿或輸入有效數值會立即影響預覽；原生模式只更新手動清單。直向控制在取景器下方，橫向控制在側邊窄列，調整與輸入期間保持預覽可見。
- 直向工具列在取景器上方，調整與快門整合在底部圓角面板；收合時可用配方快捷列切換。橫向面板維持滿高，參數列表可以捲動，下方固定數值與滑桿；數字鍵盤利用面板高度。
- 調整面板、配方選單與數字鍵盤加入短過場，選取狀態和構圖輔助線使用淡化；遵循系統「減少動態效果」，不對即時相機數值套用延遲動畫。
- 「拍攝」控制 ISO、快門、對焦、白平衡、拍攝亮度與變焦。這些硬體設定和配方調色各自控制；可恢復自動模式。快門接受分數或秒數，ISO／快門使用對數滑桿。
- 點取景器對焦；前鏡頭與橫直向的點選座標會換算回感測器座標。手動曝光不會因點對焦而改回自動。
- 取景器底部的倍率列可直接選擇可用倍率，箭頭展開變焦滑桿，上限 10×。後置優先使用系統三鏡頭／雙鏡頭裝置，由 AVFoundation 隨倍率、光線與對焦切換實體鏡頭；有超廣角時提供 0.5×，望遠倍率依硬體回報顯示。切換前後相機時回到顯示倍率 1×。
- 主操作列依序為圖庫、快門、翻轉相機；右側翻轉按鈕點一下切換前後相機。調整參數位於取景器內右下方，相機設定位於上方齒輪。
- 九宮格與水平線可分別開關；水平線使用 Core Motion，接近水平時顯示黃色。手機平放、缺少有效方向資料時不顯示，真機需驗證方向與反應。

Camlab 調色參數名稱對照 iPhone「照片」，實際使用自有 Core Image 處理，並非 Apple 私有演算法的複製。陰影與增艷的暗部依像素及鄰近亮度加權；負向亮部使用連續、單調的壓縮曲線，調色後的極亮通道再平滑收斂。色溫／色調及正向飽和度增量會依原圖暖色範圍部分衰減，以減少膚色染色；這不是人臉辨識，相近暖色物體也可能受影響。增艷不再額外增加飽和度。對比曲線保留黑白端點，色溫與飽和度在感知 RGB 中處理，色溫偏移在純黑處淡出。預覽、匯入編輯與完整尺寸成品使用同一處理函式。

目前以使用者提供的同一張夜景及八項配方完成第一輪校正，完整輸出為 5712 × 4284。轉為相同尺寸 sRGB 後，相對原生參考的平均 RGB 絕對誤差由上一版 8.91 降至 7.96（0–255 尺度）；這不是相似度百分比，也不代表其他照片或各滑桿已與原生一致。白天、人像、逆光及個別滑桿仍待原圖／原生結果對照；真機預覽效能亦待測量。既有配方數值保留，重新套用使用新版處理，已輸出照片不自動改寫。重現工具為 `Tools/Calibration/render_recipe_comparison.py` 與 `Tools/Calibration/measure_recipe_comparison.py`。

## 相簿與重新編輯（Camlab 近似模式）

照片使用獨立 `AVCapturePhotoOutput`，不使用預覽截圖。採鏡頭支援的最大、至多約 24 MP 尺寸，處理時正規化方向、保留尺寸及拍攝資訊。預覽與成品共用配方處理函式，系統拍照處理造成的差異仍需真機比較。

拍攝後自動保存到系統相簿：先建立原圖 asset，再以 PhotoKit 非破壞性編輯提交成品與配方調整資料。成功後相簿中是同一筆照片，可取回原圖重新調色。App 只持續保存配方、設定與照片識別碼；完成寫入後清除照片暫存。

儲存需要相簿讀寫權限，以便保存原圖並提交可重編輯的結果。拒絕或寫入失敗時，原圖、成品及重試資料保留於 Documents/Captures；主畫面顯示待儲存數量，可開啟並重試或分享。建立原圖後即記錄 asset 識別碼，重試會重用該 asset。未完成的拍攝暫存不自動過期。

快門左側的「圖庫」按鈕可匯入照片，有本次拍攝縮圖時顯示縮圖，否則顯示有邊框的照片圖示；橫向時位於快門上方。長按圖庫可重新開啟最近一筆。選到可存取的 Camlab 照片時讀取其原圖與調整資料，儲存更新同一筆；其他來源照片另存新的成品。若受限相簿權限無法讀取 asset，系統選圖器交付的影像會作為新匯入來源處理。

拍後調整與匯入編輯不會每次拖動就儲存，按「儲存成品」才寫入相簿；可比較來源圖、成品或分享完整尺寸 JPEG。來源圖若已有其他 App 編輯，使用 PhotoKit 可提供的編輯基底，不宣稱能重建其他 App 的配方。

從相簿匯入後，編輯頁將照片限制在可用範圍內，頂部完成按鈕與控制區底部的儲存／分享固定顯示。直向調整區位於照片下方，橫向位於右側；參數與數字鍵盤在空間不足時可捲動，配方選單使用獨立面板。原圖比較採淡入淡出。

刪除 App 會移除尚未存入相簿的暫存。從相簿刪除照片後，Camlab 不另留永久照片備份。

## 驗證與限制

單元測試涵蓋配方保存／重啟／原色／微調捨棄／改名／刪除、整數驗證、11 項參數像素變化、零值原圖、拍攝暫存與 asset 記錄／清理、點選對焦座標、水平角度，以及原有相機參數、照片方向與預覽呈現測試。

UI 測試檢查直向與橫向輸入仍有足夠預覽、配方重啟後的數值、九宮格／水平線與倍率入口。相簿整合測試限定已授權的模擬器，驗證原圖、配方資料、重複編輯同一 asset 與暫存清理。

真機需確認相機啟動、各鏡頭支援範圍、10× 操作、點對焦、感測水平線、照片尺寸與方向、相簿完整／受限／拒絕權限、背景中斷與重試，以及預覽／成品和 iPhone「照片」的效果對照。最低版本已編譯檢查，尚需 iOS 26.0 實機驗證。

相機工作與硬體變更在獨立序列佇列執行，影格只保留最新一張；Metal 預覽最多一個待完成工作。初始預覽呈現後啟動 Deferred Start 拍照輸出，延續原有啟動診斷。Xcode Console 可篩選 `CameraStartup`，其 discovery／configuration／startRunning 為工作時間，first preview presented 等為累積時間，不可相加。

完整產品規格見 [Design/Documents/ProductSpecification.md](Design/Documents/ProductSpecification.md)。即時場景與構圖建議記於 [Design/Documents/PendingFeatures.md](Design/Documents/PendingFeatures.md)，狀態待定，本次不實作。錄影、RAW、多張夜景合成與人像景深處理也未加入。
